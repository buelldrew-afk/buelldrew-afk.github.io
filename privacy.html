Sermon Uploader: Privacy Policy

Last updated: October 28, 2026

Sermon Uploader is a private tool used by Drew Buell to upload his own sermon videos to his own YouTube channel. It is not offered to the public, and no one else signs in to it.

What the app accesses

Sermon Uploader uses YouTube API Services. With the account owner's permission, it:

  • uploads sermon videos, titles, descriptions, and thumbnails to the owner's YouTube channel, and
  • reads basic information about that channel and its uploads (for example, video IDs) to confirm that each upload worked.

It does not access any other Google data, and it does not collect information about viewers.

How the data is used and stored

The sign-in token that Google issues stays on the owner's personal computer and is used only to make these uploads. Upload records (sermon title, date, and YouTube video ID) are kept in a local log so the same sermon isn't uploaded twice. Nothing is sold, shared with third parties, or used for advertising.

Google and YouTube policies

By using YouTube API Services, this app is bound by the YouTube Terms of Service. Google's handling of data is covered by the Google Privacy Policy.

Revoking access

Access can be removed at any time on the Google security settings page: myaccount.google.com/permissions. Deleting the local token file also ends the app's access.

Deleting data

To delete the app's stored data, revoke access (see above) and delete the local token file and upload log. Videos on the channel can be deleted at any time in YouTube Studio. The app keeps no copies of any data elsewhere.
